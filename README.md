# GhostDesk

GhostDesk 是一款面向 Windows 11 的桌面分区收纳工具。你可以把桌面文件、快捷方式和文件夹按自己的习惯放进不同分区，鼠标移开后分区会延迟渐隐，让壁纸重新露出来。

## 主要功能

- 创建多个独立桌面分区，可拖动位置、调整大小，并吸附到屏幕四边或彼此对齐
- 鼠标悬停显示分区，移出后按设定延迟缓慢渐隐
- 分区可收起为窄条，悬停临时展开，也可手动常驻展开
- 双击分区标题直接重命名
- 支持显示或隐藏文件扩展名
- 支持从桌面拖入文件、文件夹和快捷方式；拖入后文件留在原位置，仅记录引用并隐藏桌面图标
- 支持把分区内的项目放回桌面，或对桌面以外的项目执行「放回源路径」，只移除引用并恢复可见性
- 设置中可临时「显示隐藏文件」，以半透明样式查看收纳中的图标
- 支持在分区右键菜单中新建文件夹或文本文档，新建项目会自动避开重名
- 右键图标支持打开、管理员运行、记事本编辑 Windows 支持的文本和脚本文件、打开所在位置、复制路径、重命名、自定义图标、属性、放回桌面、删除到回收站等操作
- 重命名和自定义图标弹窗始终显示在其他窗口之上
- 一键启动：把常用软件绑定到现有分区，一次点击按设定间隔集中启动
- 系统设置中可调整隐藏延迟、渐隐时长、分区吸附、开机自启、展开触发范围和运行模式
- 配置自动备份和手动备份，支持一键恢复并自动重启应用
- 启动时检查 GitHub Releases，发现新版本后可查看下载进度并直接更新

## 使用说明

1. 启动 GhostDesk，默认会创建两个空白分区。
2. 把桌面图标拖进分区即可收纳：文件留在原位置，桌面图标被隐藏，分区里保留入口；设置中可临时「显示隐藏文件」查看。
3. 鼠标移出分区后，等待设定的延迟时间，分区会逐渐隐身。
4. 右键托盘图标可打开系统设置、检查更新、执行一键启动或退出程序。
5. 双击托盘图标可切换分区的常驻显示与自动隐藏状态。

GhostDesk 不拦截系统 `Win + D`，也不注册额外全局热键，避免干扰全屏游戏和系统桌面切换。

## 配置与备份

配置和备份默认保存在当前用户目录：

```text
%APPDATA%\GhostDesk\config.json
%APPDATA%\GhostDesk\backups
```

更新和重装不会覆盖配置。旧版本放在 exe 同目录 `GhostDeskData` 中的配置会在第一次启动时自动迁移。

## 收纳方式

GhostDesk 不会搬动、复制或删除你的文件。

- **桌面上的文件 / 文件夹 / 快捷方式**：拖进分区后，只在原地给文件加「隐藏」属性，桌面图标消失，文件仍留在桌面目录里，分区内保留入口。放回桌面时只移除引用并恢复可见性。
- **桌面以外的文件 / 文件夹**：在它所在目录生成一个同名 `.lnk` 快捷方式，分区引用这份快捷方式，源文件的位置和属性都不会被改动。重命名、删除只作用于快捷方式；直接引用的项目点删除时只移除分区记录，不会删源文件。
- **显示隐藏文件**：设置里的开关是临时查看，只修改资源管理器的「显示隐藏的项目」设置，隐藏项会以半透明样式出现；关掉开关或退出程序会自动还原，文件属性始终不变。
- **退出程序**：会询问是否把收纳区图标恢复到桌面。选择恢复后配置仍然保留，下次启动会按原配置重新收纳。

程序不创建收纳目录，也不保存文件副本。配置与备份位于 `%APPDATA%\GhostDesk`。
